[The Great Reading Adventure version 4.7.1](https://github.com/MCLD/greatreadingadventure/releases/tag/v4.7.1) has been released.

There is no upgrade path from versions 1, 2, or 3 to version 4 due to significant architectural changes.
{: .notice--warning}

Notable changes:

- Update all libraries/Docker references to .NET 8.0.34
- Add site setting "Disable Crop" to support full-height avatars
- Proper avatar access in Mission Control if only one avatar layer
- Limit maximum size of avatar thumbnails on alt text entry page

For more information, please see [the release notes](https://github.com/MCLD/greatreadingadventure/releases/tag/v4.7.1) and [the manual](http://manual.greatreadingadventure.com/en/v4.7.1/).
