## Release Notes: 4.7.0

### Introduction

The Great Reading Adventure is a robust, open source software designed to manage library reading programs. The GRA is free to use, modify, and share. Check out [www.greatreadingadventure.com](http://www.greatreadingadventure.com/) for an overview of its functionality and capabilities.

Source code to The Great Reading Adventure can be found on [GitHub](https://github.com/MCLD/greatreadingadventure) and [Codeberg](codeberg.org/MCLD/greatreadingadventure).

### Release

These release notes accompany **[:books: The Great Reading Adventure version 4.7.0](https://github.com/MCLD/greatreadingadventure/releases/download/v4.7.0/GreatReadingAdventure-4.7.0.zip)** which can be downloaded from GitHub or run in Docker from the [Docker Hub](https://hub.docker.com/r/mcld/gra) or [GitHub Packages](https://github.com/MCLD/greatreadingadventure/pkgs/container/gra).

### Upgrading

If you wish to upgrade from a previous release of version 4 see the [upgrading section](http://manual.greatreadingadventure.com/en/v4.7.0/installation/upgrading/) of the manual. There is no upgrade path from versions 2 or 3 to this release due to significant architectural changes.

### Documentation

For information on what is required to run the Great Reading Adventure, please refer to the [online manual](http://manual.greatreadingadventure.com/en/v4.7.0/). The software requires a [hosting environment including Microsoft .NET 8.0 and Microsoft SQL Server](http://manual.greatreadingadventure.com/en/v4.7.0/installation/system-requirements/). If you don&rsquo;t have such an environment, there are plenty of Web hosting services you can use.

### Changes in this release

Notable changes:

- Improvement of accessibility to avatar system - all elements now have alt tags
- Ability to import and export avatars seamlessly including localized text
- Ability to generate QR codes in-software
- Continued improvement in internationalization/localization
- Revamped and improved personal participant point goal
- Ability to prune inactive users
- System setting to require email address for participants to join
- Allow drawing mail to be sent after drawing selections are made
- Remove delay in back-end email submission
- Fix issue with damaged/missing selection on vendor code packing list
- Improve back-end so bulk emails are only sent to an address once
- Additional functional and usability bug fixes and improvements

For more detailed information about changes in this release please review the [change log](https://github.com/MCLD/greatreadingadventure/blob/v4.7.0/CHANGELOG.md).
